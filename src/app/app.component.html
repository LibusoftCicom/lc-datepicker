Description

A pure Angular date and time picker component.

  • LC DatePicker is an Angular component that generates a datepicker calendar on your input element
  • Compatible with Angular 2+ up to Angular v18.0.0
  • Only dependencies are RxJS and Font Awesome
  • Customizable language
  • Can be configured as time, date-time, date, month or year picker

Getting Started

  1. Fork and clone this repo
  2. npm install
  3. Open a terminal and type "npm run start"
  4. Open "http://localhost:4200" in the browser

Installation

Add LC DatePicker to an existing Angular application in four steps.

  1. Install the package

    npm install @libusoftcicom/lc-datepicker

  2. Register the module and a date adapter

    Add these entries to your existing module. The adapter is an application service, not a library export. Use the demo's Moment adapter (requires moment and moment-timezone) or Luxon adapter (requires luxon), or implement LCDatePickerAdapter yourself.

    app.module.ts · module additions
    import { LcDatePickerModule } from '@libusoftcicom/lc-datepicker';
import { MomentDateAdapterService } from './moment-date-adapter.service';


  ...
  imports: [
    ...
    LcDatePickerModule.withImplementation({ adapter: LuxonDateAdapterService })
    // or LcDatePickerModule.withImplementation({ adapter: MomentDateAdapterService })
    // It is also possible to extend LCDatePickerAdapter and implement the adapter using a different library.
  ],
  providers: [ ... ]

  3. Create a configuration

    The value is an ISO 8601 string. Other settings are optional and keep their defaults when omitted.

    app.component.ts
    import { Component } from '@angular/core';
import {
  DatePickerConfig,
  ECalendarType,
  LCDatePickerAdapter
} from '@libusoftcicom/lc-datepicker';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  public selectedDate: string;
  public datePickerConfig: DatePickerConfig;

  constructor(private readonly dateAdapter: LCDatePickerAdapter) {
    const timezone = 'Europe/Zagreb';
    this.selectedDate = this.dateAdapter.toISOString(
      this.dateAdapter.now(timezone)
    );

    this.datePickerConfig = new DatePickerConfig({
      value: this.selectedDate,
      calendarType: ECalendarType.Date,
      localization: 'hr',
      timezone
    }, this.dateAdapter);
  }
}

  4. Add the picker to your template

    Open the calendar with a button and store the selected value with dateChange.

    app.component.html
                    <p>Selected date: {{ selectedDate }}</p>
<button type="button" (click)="datePickerConfig.setOpen(true)">
  Choose date
</button>

<lc-datepicker
   [config]="datePickerConfig"
   (openedChange)="setDatePickerOpen($event)"
   (dateChange)="setCalendarDate($event)"> 
 </lc-datepicker>
Optional: use a date range picker

Add a dateRangePickerConfig: DatePickerConfig property to your component and initialize it in the constructor. Separate the start and end ISO values with /.

app.component.ts · constructor addition
const today = this.dateAdapter.today(timezone);
const tomorrow = this.dateAdapter.add(today, 1, 'day');

this.dateRangePickerConfig = new DatePickerConfig({
  value: this.dateAdapter.toISOString(today)
    + '/' + this.dateAdapter.toISOString(tomorrow),
  calendarType: ECalendarType.DateRange,
  timezone
}, this.dateAdapter);
app.component.html
<button type="button" (click)="dateRangePickerConfig.setOpen(true)">
  Choose date range
</button>

<lc-date-range-picker
   [config]="config"
   (openedChange)="setDateRangePickerOpen($event)"
   (dateChange)="setCalendarDateRange($event)">
 </lc-date-range-picker>

3. Configuration and API reference

Use these options when creating a DatePickerConfig. All values are optional except value; omitted options keep their documented defaults.

IDatePickerConfiguration properties

Options passed to the picker configuration:

  • value: string — ISO date/time, or start/end for a date range (required).
  • calendarType?: ECalendarType — Time, DateTime, Date, MonthYear, Year or DateRange.
  • theme?: IColorTheme — fallback primary and font colors.
  • labels?: ILabels — confirm, From/To and optional time labels.
  • hourFormat?: EHourFormat — 12-hour or 24-hour time display.
  • localization?: string — locale used for date and weekday labels.
  • minimumDate?: string, maximumDate?: string — selectable date bounds.
  • disabledDates?: string[] — dates that cannot be selected.
  • disabledTimeRanges?: IDisabledTimeRange[] — time intervals that cannot be selected.
  • dateEvents?: IDatePickerEvent[] — event markers and accessible descriptions; not restrictions.
  • timezone?: string — timezone used to interpret and format dates.
  • open?: boolean — initial open state.
  • selectionMode?: 'immediate' | 'explicit' — commit each selection or wait for confirmation.
  • rangeSelectionMode?: 'independent' | 'linked' — independent endpoints or a shared two-click range.
  • rangeNavigationMode?: 'independent' | 'synchronized' — how linked range panels navigate together.
  • view?: IDatePickerViewOptions — opt-in layout for adjacent days, compact labels/time, and year grid.
  • view.yearColumns?: 4 | 5 — number of columns in the year grid.
  • view.yearPageAnchor?: number — first year in the displayed year group.

Define allowed/disabled time ranges:

To configure disabled time ranges use the disabledTimeRanges property of the IDatePickerConfiguration interface. Everything in the specified range will be disabled.

constructor(
 ...
 private readonly dateAdapter: LCDatePickerAdapter,
) {
 ...
 const configuration = {
  ...
  disabledTimeRanges: [
    {startTime: {hour: 0, minute: 0}, stopTime: {hour: 7, minute: 59}}
    {startTime: {hour: 14, minute: 0}, stopTime: {hour: 16, minute: 59}}
    ...
  ]
 }
 const config = new DatePickerConfig(configuration, this.dateAdapter);
}

If is pressed and the current time is in the disabled time range, the calendar will pick the next available time.


Navigation

It is possible to navigate through the grid of each component, so each developer can implement keyboard or any other navigation using DatePickerConfig methods.

...
const config = new DatePickerConfig();
config.navigateUp();
config.navigateDown();
config.navigateRight();
config.navigateLeft();
config.nextPage();
config.previousPage();
config.confirm();
config.close();

Example:
this.renderer.listen('document', 'keydown', (event: KeyboardEvent) => {
 if (!this.config.isFocused()) {return;}
 event.preventDefault();
 if (event.key === "ArrowUp") {this.config.navigateUp();}
 if (event.key === "ArrowDown") {this.config.navigateDown();}
 if (event.key === "ArrowRight") {this.config.navigateRight();}
 if (event.key === "ArrowLeft") {this.config.navigateLeft();}
 if (event.key === "Enter") {this.config.confirm();}
 if (event.key === "Escape") {this.config.close();}
 if (event.key === "PageDown") {this.config.nextPage();}
 if (event.key === "PageUp") {this.config.previousPage();}
});
